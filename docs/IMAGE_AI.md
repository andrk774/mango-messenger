# Создание стикеров с ИИ

Android: меню чата ⋮ → Стикеры → Создать. Описание, индикатор ожидания,
предпросмотр, новый вариант и отправка PNG обычным вложением.
Кнопка скрыта при недоступном сервере, выключенном генераторе, отсутствии ключа
или до успешной проверки сохранённого подключения.

Админ-панель → Настройки сервера → ИИ · генератор стикеров:
1. Указать модель OpenAI Images (по умолчанию `gpt-image-1.5`) и API-ключ.
2. Включить генератор и сохранить.
3. Проверить сохранённое подключение. Изменение настроек сбрасывает проверку.

Проверка модели не подтверждает платёжный баланс и возможность реальной генерации.
Ключ не возвращается API и не передаётся Android. Пустое поле сохраняет прежний ключ.
Для шифрования используется отдельный производный ключ от серверного
`MANGO_CALLS_KEY_FILE`; этот файл должен входить в защищённую резервную копию.
Провайдер и HTTPS-адрес фиксированы: произвольные URL не принимаются.
Описание отправляется провайдеру; переписка не передаётся.

Лимит генератора — 5 попыток за 24 часа на пользователя, включая неудачные.
Это не ограничение количества сообщений или истории чата.
UUID запроса сохраняется в БД: повторный HTTP-запрос не запускает платную генерацию повторно.
При потере ответа полученное изображение восстановить автоматически нельзя;
новая ручная генерация будет отдельной попыткой. Сервер хранит только ID попытки,
пользователя и дату, без описания и результата. Открытый экран временно хранит PNG
в кэше Android; отправка использует существующую очередь вложений.

Проверки: три backend-теста (валидация, роли, API выключенного генератора),
Android release-сборка и синтаксис JavaScript. Реальная генерация требует
ключа, доступа к модели и баланса; без них не проверена.

Контракт провайдера: https://developers.openai.com/api/reference/resources/images/methods/generate
