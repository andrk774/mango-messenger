# Аудио и видео Mango

## Что добавлено

Кнопки аудио/видеозвонка в чате веб-клиента и Android. Общий экран LiveKit с сеткой участников, индикатором говорящего, микрофоном, камерой, переподключением и выходом. Одна комната на личный или групповой чат, до 12 подключений. Android открывает экран во внутреннем WebView, с отдельными системными разрешениями на камеру/микрофон. Учётные JWT приложения не передаются странице.

В веб-клиенте открытый чат опрашивает активные комнаты каждые 15 секунд и предлагает присоединиться. Это **не полноценная система входящих звонков**: фоновые вызовы через FCM, системный экран входящего звонка, вибрация, журнал пропущенных и работа Android с выключенным экраном ещё не реализованы. Android-звонок прекращается при уходе приложения с переднего плана. Второе подключение с тем же sessionId заменяет первое в LiveKit.

## Настройка оператора

Сервер звонков по умолчанию выключен. Backend возвращает понятную ошибку, пока не настроены:

- `LIVEKIT_URL`: адрес, доступный клиентам, например `wss://calls.example.org`.
- `LIVEKIT_API_KEY`: отдельный ключ LiveKit.
- `LIVEKIT_API_SECRET`: отдельный случайный секрет длиной не менее 32 символов. Не использовать JWT/SMTP/Firebase ключи Mango.
- `LIVEKIT_INTERNAL_URL`: необязательный адрес серверного API, например `http://livekit:7880` внутри Compose.

Для самостоятельного размещения подготовьте `secrets/calls/backend.env` с этими переменными и `secrets/calls/livekit.yaml`:

```yaml
port: 7880
rtc:
  tcp_port: 7881
  udp_port: 7882
  use_external_ip: true
keys:
  YOUR_API_KEY: YOUR_RANDOM_SECRET_AT_LEAST_32_CHARACTERS
room:
  max_participants: 12
  empty_timeout: 60
```

Замените placeholders собственными значениями, не коммитьте файлы. Каталог secrets исключён из Git. Затем используйте основной Compose вместе с `infrastructure/docker/compose.calls.yml`. Нужны HTTPS/WSS reverse proxy с доверенным сертификатом, разрешённые медиа-порты и TURN для сетей, блокирующих прямой UDP/TCP. Веб-страница Mango должна быть в secure context. `ws://127.0.0.1:7880` разрешён только для проверки на самом ноутбуке: на Galaxy этот адрес не ведёт на ноутбук.

Документация: [порты и firewall](https://docs.livekit.io/transport/self-hosting/ports-firewall/), [токены и права](https://docs.livekit.io/frontends/reference/tokens-grants/).

## Доступ и границы безопасности

- Вход только для действующего участника чата с подтверждённым email и незаблокированным аккаунтом.
- Join JWT действует 60 секунд, ограничен одной комнатой и публикацией микрофона/камеры; административных прав в нём нет.
- LiveKit API key/secret не попадают в клиент. Токен соединения хранится только в памяти.
- Backend каждые 10 секунд проверяет участников комнат Mango и удаляет тех, кто вышел из чата, заблокирован или отозвал сессию. Это периодическая проверка, не мгновенный отзыв. При недоступности административного API немедленное отключение не гарантировано.
- Доступ к endpoint join ограничен 10 запросами в минуту на аккаунт; список комнат — 20. Используется общий лимитер Mango (Redis, если настроен).
- **E2EE для звонков не реализовано.** WebRTC шифрует транспорт до медиа-сервера; не следует обещать сквозное шифрование.
- Участники присоединяются самостоятельно. Камера/микрофон запрашиваются после кнопки «Подключиться». Приложение не включает запись звонков.
