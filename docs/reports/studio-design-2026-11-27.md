# Дизайн Mango — 27 ноября 2026

## Изменения

- Веб: зелёная навигация, активная вкладка цвета манго, светлая боковая панель, выразительное выделение текущего чата.
- Мягкие поверхности сообщений, более читаемые метаданные, крупные кнопки композера, состояния фокуса для клавиатуры.
- Поиск чатов доступен и на узких экранах. Обновлены карточки задач, Kanban, формы входа и диалоги.
- Учитывается системное предпочтение уменьшенной анимации. Для стабильных браузерных снимков тест использует reducedMotion.
- Android: зелёная основная палитра, светлые зелёные исходящие сообщения, согласованные поверхности настроек; аватар профиля уменьшен с 104 до 80 dp, заголовок компактнее. Тёмные исходящие сообщения имеют зелёную поверхность.
- Скрипт сборки поддерживает -Offline и не останавливается на предупреждениях native stderr; ошибка Gradle определяется по коду завершения.
