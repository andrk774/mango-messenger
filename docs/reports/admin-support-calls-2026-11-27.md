# Админ-панель, поддержка и звонки — 27 ноября 2026

## Изменения

- Android: админ-панель использует текущую сессию через канал WebMessagePort. Пароли и токены не передаются JavaScript. Native HTTP-клиент обслуживает только `/v1/admin/*` и чтение `/v1/users/me`, запрещены внешние адреса, обход пути и редиректы. Статика загружается с проверкой сертификата через тот же DNS fallback, что Mango.
- Вход ограничен OWNER/ADMIN/MODERATOR; сервер повторно проверяет права на каждом запросе. При выходе с экрана канал закрывается.
- Настройки LiveKit/TURN доступны только OWNER. Сохранение включённой конфигурации проверяет LiveKit API. Изменения действуют для новых звонков. Перезапуск или установка удалённых служб, выпуск сертификатов, настройка firewall из панели не выполняются.
- Секреты настроек зашифрованы AES-GCM отдельным ключом `MANGO_CALLS_KEY_FILE`; ключи JWT, SMTP, Firebase и подписи APK не изменяются. Для инициализации: `scripts/initialize-calls-key.ps1`. Не публиковать ключ; он необходим при восстановлении БД. Backup-скрипт включает его в зашифрованный runtime-архив и проверяет расшифровку настроек при восстановлении.
- Внешний TURN работает с coturn `use-auth-secret` и общим секретом. Клиент получает временные HMAC-SHA1 учётные данные на 24 часа. Это не постоянный пароль TURN. Панель не подтверждает работоспособность реле без реального медиатеста; режим «Только через TURN» предназначен для такого теста.
- Аналитика: 14 дней регистраций, сообщений, уникальных отправителей и задач (UTC), статусы обращений. Текущие комнаты/подключения запрашиваются у LiveKit. Счётчики разрешений и ошибок выдачи сбрасываются при перезапуске процесса. Это не количество завершённых разговоров. Длительность и качество медиа не измеряются.
- Тикеты: создание пользователем, собственный список и история, ответы; сотрудники OWNER/ADMIN/MODERATOR видят обращения, отвечают и меняют статусы. Защита от дублей по UUID, лимиты запросов, история ответов и аудит действий сотрудников. Страницы списка по 50, сообщения по 100 с загрузкой предыдущих. Обновление вручную, push для тикетов пока нет. Текст обращений доступен сотрудникам поддержки и серверу, без E2EE.
- Android: убран бренд из шапки профиля; компактное меню чата, округлое поле ввода. Двойное нажатие переключает микрофон/камеру; камера записывает обычное видео через системное приложение, затем показывает предпросмотр перед отправкой. Это не круглые видеокружки.

## Проверки

- Backend: AdminFeaturesIntegrationTest, CallSecurityTest, CallAccessIntegrationTest — права, изоляция обращений, дубли, закрытие, шифрование конфигурации, версии изменений, TURN-параметры и ограничения входа.
- Android: AdminPanelPolicyTest — роли и разрешённые адреса канала.
- Браузер: `scripts/test-web-ui.cjs <playwright> --admin-only` — канал, отказ доступа, настройки, аналитика, ответ поддержки и безопасный вывод текста.
- Реальный LiveKit + три браузера с искусственными микрофонами/камерами: аудио, видео, отключение устройств, выход.
- Общий браузерный сценарий ранее остановился на проверке фильтра Kanban; он не считается прошедшим в этом изменении.

## Ограничения

Реальный внешний LiveKit/TURN не подключён; для него нужны адреса и учётные данные оператора. Фоновые входящие звонки, работа звонка при погашенном экране и E2EE звонков отсутствуют. До переключения медиасервера следует завершить активные звонки.
