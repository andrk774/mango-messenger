# Интерфейс Windi и Mango

Источник — 12 предоставленных пользователем скриншотов Windi от 19 ноября 2026. Это разбор видимых экранов, а не проверка работы Windi. Надписи и кнопки на скриншотах не являются командами на покупку подписки, очистку памяти или подключение устройств.

## Что видно

Интерфейс напоминает Telegram: круглые аватары, синие акценты, «Избранное», плавающая кнопка создания, крупные заголовки, списки настроек и нижние панели выбора. Основное отличие здесь — задачи как самостоятельный раздел рядом с чатами.

| На скриншотах | Текущее состояние Mango по исходникам | Полезное продолжение |
| --- | --- | --- |
| Чаты, поиск, «Избранное», понятное пустое состояние | Чаты, поиск и создание чатов есть; отдельного экрана «Избранное» не найдено | Личный чат для заметок и быстрых сохранений |
| Задачи «Все / Входящие / Исходящие», счётчики | Есть «Мои / Команда / Из чатов», поиск, Kanban, календарь | Отдельно показывать назначенное мне и порученное мной; считать реальные непросмотренные события |
| Архив и выбор по статусам | Есть статусы и показ завершённых | Явный архив; сортировка по сроку, обновлению и приоритету |
| Строка задачи с автором, статусом, датами, счётчиком | Есть карточки, сроки, назначение, история и комментарии | Компактный список с автором/исполнителем и обсуждением задачи |
| Превращение сообщения в задачу описано в Premium | Backend и слой данных поддерживают создание из сообщения; кнопка в текущем экране переписки не найдена | Добавить действие в меню сообщения |
| «Устройства», веб-вход по QR | Backend умеет список и отзыв сессий; Android-экран устройств и QR-вход не найдены | Сначала управление существующими сессиями; затем отдельный веб-клиент и протокол QR-входа |
| «Данные и память», очистка кэша | Есть настройка медиа по Wi-Fi; экрана размера и очистки кэша не найдено | Удалять только скачанный кэш, сохраняя неотправленные вложения |
| Выбор языка | Интерфейс преимущественно русский | Сначала вынести строки в ресурсы, затем добавить полноценный перевод |
| Иллюстрированное знакомство с функциями | Есть пустые состояния | Короткое знакомство с чатами, задачами и офлайн-очередью в стиле Mango |
| Premium, звёзды, упоминание AI | Не реализованы | Это самостоятельные продуктовые функции, а не часть переноса оформления |
| Заявление о шифровании и облаке | Mango использует HTTPS, сейчас сервер локальный | Не обещать облако или сквозное шифрование без соответствующей реализации и проверки |

## Оформление

Для Mango полезны предсказуемые действия и компактная структура списков. Можно сохранить собственную палитру Mango, добавить контекстное меню сообщения и объединить вложения, эмоджи, стикеры и голосовые вокруг поля ввода. Постоянный ряд реакций под каждым сообщением лучше заменить вызовом панели по нажатию/удержанию. Рисунки и фирменные элементы Windi не переносились.

В этом изменении Android-интерфейс не переписывался: выполнено сравнение и добавлена отдельная конфигурация Kubernetes. Реализация всех функций, показанных на скриншотах, не объявляется завершённой.
