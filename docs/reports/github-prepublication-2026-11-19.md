# Проверка перед публикацией GitHub

Начата 19 ноября, завершена 20 ноября 2026 года. Проверка локального репозитория;
публикация и изменение истории не выполнялись.

## Область проверки

- Gitleaks 8.30.1 со стандартными правилами, вывод и JSON с `--redact=100`.
- История: `gitleaks git . --log-opts="--all --full-history"`; 6 коммитов,
  доступных из 7 локальных refs. Удалённые ветки не загружались.
- Рабочие файлы: отдельный временный снимок 374 отслеживаемых и неигнорируемых
  новых файлов, выбранных через `git ls-files --cached --others --exclude-standard`.
  Проверка выполнена командой `gitleaks dir <snapshot>`.
- Дополнительно проверены имена файлов среди 1753 достижимых Git-объектов:
  секретные каталоги, `.env`, ключи подписи, Firebase credentials и архивы ключей не найдены.
- 620 исторических blob-объектов и текущие файлы сопоставлены с 29 вариантами
  значений из локальных секретных настроек и приватного ключа Firebase.
  Сами значения в отчёт не включались.

## Результаты и разбор срабатываний

Gitleaks обнаружил по два срабатывания в истории и текущих исходниках:
`backend/notifications/src/test/kotlin/com/mango/backend/notifications/FcmPushProviderTest.kt`,
строки 60 и 142; исторический коммит `f8e43c2`.
Оба относятся к строковым маркерам PEM. Между ними код вставляет результат
`Base64...encodeToString(keys.private.encoded)`, а RSA-пара генерируется через
`KeyPairGenerator` при выполнении теста. Статического приватного ключа там нет.
Проверена как текущая, так и историческая версия. Эти срабатывания признаны ложными;
широкие исключения для тестов или приватных ключей не добавлялись.

Сопоставление локальных значений нашло только `MINIO_PASSWORD` из шаблона
`.env.example` (в том числе в трёх исторических версиях). Локальная настройка
повторяет демонстрационное значение. Текущий Compose не содержит сервиса MinIO;
это не обнаружение утечки действующего ключа Firebase или JWT. При использовании
MinIO в другой установке демонстрационный пароль необходимо заменить.

Подтверждённых действующих секретов в проверенных исходниках и истории не обнаружено.
Это результат указанной проверки, а не гарантия отсутствия любых секретов.

## Изменения

- В основном `.gitignore` закреплены `/artifacts/`, `.env.*` с исключением для
  `.env.example`, расширения PKCS12/PFX, `.key`, DPAPI и файл пароля восстановления.
  Ранее `artifacts` защищался вложенным локальным `.gitignore`.
- README обновлён по текущей структуре кода: Android, веб-клиент, администрирование,
  локальная расшифровка, задачи, рефералы; внешние ИИ и платежи отмечены как неподключённые.
- Убраны устаревшие общие числа тестов и утверждение, что уже реализованные функции
  ещё отсутствуют. Добавлены команды сборки, ограничения локальной установки и лицензирования.

## Ограничения

Игнорируемые `.env`, `secrets`, сборки, логи, резервные копии и пользовательские
материалы не являются разрешённым содержимым публикации. Не используйте `git add -f`
для их добавления. Часть локальных секретов читалась только для проверки совпадений;
полный аудит их содержимого не проводился. Reflog, недостижимые объекты, внешние
репозитории и неизвестные удалённые refs не входили в аудит. Скриншоты и APK
не подготовлены к публичному релизу и требуют отдельной проверки личных данных.

Локальные результаты с замаскированными находками сохранены в игнорируемом
`artifacts/github-*-scan.json`; рядом находятся логи и результат сопоставления
известных секретов. Не публикуйте каталог artifacts целиком.

Приложение и сервер в этой проверке не пересобирались, тесты не запускались:
изменения касаются документации и исключений Git. После аудита, 20 ноября 2026 года,
по запросу владельца добавлена открытая лицензия MIT (см. `LICENSE` в корне).
Перед публикацией следует повторить сканирование после окончательного набора изменений.
