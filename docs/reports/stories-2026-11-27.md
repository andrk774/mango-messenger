# Истории Mango: первый этап — фотографии

## Реализовано

- Истории фотографий в Android (в списке чатов) и веб-клиенте.
- Срок 24 часа устанавливает PostgreSQL. Клиент не может продлить его при публикации или повторе запроса.
- Просмотр доступен автору и пользователям с подтверждённым email из **облачной книги автора**. Телефон не используется для авторизации: его владение пока не подтверждается.
- Проверка срока, блокировки и доступа выполняется отдельно для списка и получения изображения. Прямой публичной ссылки на фото нет; ответ `no-store`.
- Автор может скрыть историю раньше. Удаление контакта из облачной книги отзывает доступ, если не осталось другой записи с тем же email.
- Лимит 20 публикаций за скользящие 24 часа, включая скрытые истории. Повтор с тем же ID не создаёт дубль; изменение изображения под опубликованным ID отклоняется.
- Сервер проверяет размеры до декодирования и перекодирует изображение в JPEG, удаляя EXIF и другие метаданные. Максимум 1440 × 1920, 1,5 МБ.
- Редактор: текст и эмодзи, выбор, перемещение, масштаб, поворот, удаление наклеек. Наклейки сохраняются в пикселях отправляемого изображения.
- В Android очки и корона автоматически размещаются по найденному на фото лицу. `android.media.FaceDetector` работает локально. Если лицо не найдено, доступно ручное размещение.

## Ограничения — не считать завершёнными

- Это **фотоистории**. Видеоистории и маски с отслеживанием лица во время съёмки ещё не реализованы. Системная камера Android возвращает предварительный снимок, а не оригинал высокого разрешения; для качества лучше выбрать фото из галереи.
- В браузере маски размещаются вручную; автоматическое определение лица есть только в Android.
- Истечение срока скрывает историю и запрещает выдачу изображения, но не уничтожает строку с изображением в PostgreSQL. Политику физической очистки и резервных копий нужно согласовать отдельно. Сохранённые зрителем копии отозвать нельзя.
- E2EE для историй не реализовано: сервер обрабатывает изображение. В существующую историю сообщений и её ключи изменений нет.
- Порядок доступа зависит от актуального содержимого облачной книги автора. Новые контакты получают доступ и к ещё не истёкшим историям.
- Release APK установлен на Galaxy без удаления данных; локальный backend обновлён, экран историй проверен на телефоне. Публикация фото и распознавание лица на Galaxy пока не приняты. Подробности: `device-acceptance-2026-11-27.md`.

## Проверки

- `StoriesIntegrationTest`: настоящий PostgreSQL; изоляция контактов, запрет самостоятельного получения доступа, отзыв контакта, TTL для списка и оригинала, повтор публикации, удаление чужой истории, невалидные изображения.
- `scripts/test-web-ui.cjs`: выбор фото, наклейка и текст, публикация, открытие, скрытие; полный набор существующих браузерных сценариев.
- `StoryEditorTest`: реальные пиксели при native graphics Robolectric, сохранение текста, перемещение и поворот, неизменность исходного Bitmap.
- Результат первого завершённого прогона: 3 теста историй и 3 теста промокодов/контактов прошли; браузерный набор прошёл; 43 unit-теста Android app прошли, включая 2 теста редактора. Debug APK собран, Lint — 0 ошибок.
- Логи: `artifacts/stories-backend.log`, `artifacts/stories-web.log`, `artifacts/stories-android-tests.log`.
- Скриншот браузерного теста: `artifacts/web-acceptance/stories-editor-fixture.png` (тестовые данные).
