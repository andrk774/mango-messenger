# Профиль и настройки Mango

Экран настроек переработан по предоставленному примеру: крупный аватар с камерой,
имя, блок аккаунта, компактная шапка при прокрутке и строки разделов с цветными
иконками. Переключатели перенесены на отдельные страницы. Email отображается
из приватного API текущего пользователя; номер телефона не имитируется.

Редактор имени, username и описания сохраняет данные через новый
`PATCH /v1/users/me`. Сервер проверяет длины, формат и уникальность username.
Изменить можно только собственный профиль. Android обновляет локальную запись
после успешного ответа. Смена пароля использует существующий сценарий с кодом
из email; после сброса требуется повторный вход.

Проверки: ProfileIntegrationTest (сохранение, повторное чтение, конфликт username,
изоляция аккаунтов, валидация, отсутствие авторизации); 22 Android app unit-теста.
Release lint и проверка подписи APK. Backend пересобран и обновлён, health HTTP 200.

Артефакты: `artifacts/mango-profile-release-20261119.apk`,
`artifacts/profile-backend-test.log`, `artifacts/profile-android-tests.log`,
`artifacts/profile-release-build.log`.

Реферальная программа, Energy, новые способы оплаты и чат поддержки не добавлены
как фиктивные пункты. Это изменение профиля и существующих настроек.
