# Ссылки, стикеры, эмоджи и совместные задачи — 19 ноября 2026

## Изменения

- Ссылки HTTP/HTTPS в тексте сообщений распознаются и подчёркиваются. Нажатие открывает выбор «Открыть» / «Копировать». Ошибка запуска браузера оставляет возможность скопировать адрес.
- Панель из 54 эмоджи добавляет выбранный символ в конец набранного сообщения.
- Встроенный набор из 12 статических стикеров Mango: прозрачные PNG 512×512 с эмоджи и подписью. «Своя картинка» открывает системный выбор PNG/JPEG/WebP/GIF. Они отправляются через существующий механизм изображений и офлайн-очередь; отдельного протокола пакетов стикеров и гарантии анимации GIF нет.
- Доступно 30 реакций; сохранены три быстрые кнопки, остальные открываются кнопкой «＋». Нажатие уже установленной реакции переключает её. Allowlist backend и OpenAPI согласованы с Android.
- При создании задачи можно выбрать чат. После создания открывается карточка для назначения исполнителей. Личные задачи остаются личными; существующие задачи автоматически не переименовываются и не переносятся.
- Карточка задачи загружает актуальный список участников. Назначение доступно после синхронизации задачи, повторные нажатия во время запроса блокируются, ошибки сети не выдаются за сохранённое назначение.
- После получения событий создания чата/добавления участников Android загружает доступные задачи. Это устраняет пропуск старых задач при вступлении в уже существующую группу: события их создания не адресовались новому участнику.
- При возвращении на экран задач выполняется сверка с сервером. Задачи чата доступны участникам в «Команда», назначенные задачи дополнительно доступны исполнителю в «Мои».
