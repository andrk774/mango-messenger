# Android: иконка и встроенная админ-панель

## Изменения

- Основная адаптивная и круглая иконки: манго на зелёном фоне, отдельная монохромная маска для тематических значков Android.
- Настройки → Иконка приложения: выбор PNG/JPEG/WebP до 5 МБ, ограничение размеров декодирования, обрезка по центру до 256×256. Изображение хранится в приватных настройках телефона и показывается в заголовке настроек Mango. Это не аватар пользователя и не загрузка на сервер.
- Кнопка добавления/обновления собственного ярлыка использует ShortcutManager и подтверждение лаунчера. Используется постоянный ID, чтобы обновлять существующий ярлык. Основная иконка в списке приложений не заменяется пользовательской картинкой.
- Настройки → Админ-панель открывает внутреннюю, неэкспортируемую Activity с WebView. Пункт виден только OWNER/ADMIN/MODERATOR; USER, неизвестная роль и неподтверждённый доступ скрывают пункт.
- Activity повторно проверяет роль текущего аккаунта через сервер, затем проверяет её каждые 30 секунд в активном состоянии. При отказе/ошибке окно панели уничтожается. Серверные проверки отдельных административных операций остаются обязательными.
- Встроенная веб-панель запрашивает отдельный вход, не получает Android-токены через JavaScript и уничтожает свою сессию при уходе экрана в фон. Доступ к файлам, сторонним origin, всплывающим окнам и смешанному HTTP/HTTPS-контенту отключён. Проверка TLS не обходится.

## Проверки

`AdminPanelPolicyTest` и `AppIconDecodeTest`: 4 теста прошли (роли, origin, обработка картинки, отказ для неверного/слишком большого файла). Компиляция Android прошла.

Release APK собран существующим ключом подписи: `artifacts/releases/mango-20261126-icons-admin-release.apk`. Проверка `apksigner verify --verbose` прошла (v2). R8 выдал предупреждения о метаданных Kotlin; сборка и lintVital завершились успешно, но проверка поведения оптимизированной сборки на телефоне остаётся необходимой.

Проверка на Galaxy не выполнялась: пользователь выбрал только сборку APK. Добавление ярлыка зависит от поддержки домашним экраном. Встроенный WebView использует DNS Android: для локального `mango.home.arpa` имя должно разрешаться на телефоне; резервный DNS OkHttp не распространяется на WebView. При сетевой ошибке панель показывает сообщение и остаётся внутри приложения.

Основные файлы: `AppIconSettings.kt`, `AdminPanelPolicy.kt`, `AdminPanelActivity.kt`, `ProfileSettings.kt`, `SettingsScreen.kt`, `AndroidManifest.xml`, ресурсы `ic_launcher*`.
