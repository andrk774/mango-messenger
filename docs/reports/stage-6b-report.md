## 2. Что сделано

**Сервер — модуль `notifications`:**

- `PUT/DELETE /v1/users/me/devices/push` — токен привязывается к
  устройству текущей сессии; тот же токен у другого устройства снимается.
- FCM HTTP v1 без клиентской библиотеки Google: JWT сервисного аккаунта
  подписывается средствами JDK, токен доступа кешируется на час.
- Push о новом сообщении — всем участникам, кроме отправителя; системные
  сообщения о составе группы не будят телефон.
- Payload — только идентификаторы (ADR-0010). Текст не проходит через Google.
- Только устройства с живой сессией: выход и отзыв сессии прекращают
  push, даже если клиент не успел снять токен. Токен, отвергнутый FCM, снимается.
- Напоминания о задачах: планировщик раз в 30 секунд, без двойной
  отправки при нескольких экземплярах; перенос напоминания включает его
  снова; выполненная задача не напоминает.
- Нет ключа или он битый — сервер работает, push пишутся в журнал.

**Android:**

- Firebase подключается, только если положен `google-services.json`:
  без него проект собирается и работает.
- Регистрация токена после входа и при каждом запуске; снятие при выходе.
- Приём push: синхронизация через журнал (до 12 секунд), затем
  уведомление из локальной базы. Текст — только при включённой настройке
  «показывать текст» (по умолчанию выключена), иначе «Новое сообщение».
- Не показываются: при открытом приложении, в заглушённом чате, при
  выключенных уведомлениях в настройках.
- Нажатие открывает чат или раздел задач.
- Разрешение на уведомления (Android 13+) запрашивается один раз после входа.

## 4. Ограничения и найденное

- **Потерянный push не повторяется.** Сбой FCM пишется в журнал, но
  отправка не ставится в очередь. Сообщение не теряется — оно придёт
  через журнал при открытии, — но уведомления не будет.
- **Напоминание при сбое не повторится:** отметка ставится до отправки,
  чтобы не было двойных. Потерянное лучше двойного, но это осознанный размен.
- Push о назначении задачи и комментариях не отправляются — только
  сообщения и напоминания.
- Заглушение чата хранится только на устройстве: сервер шлёт push,
  телефон его не показывает. Трафик тратится впустую.
- Нет списка уведомлений в приложении (таблица `notifications` в схеме есть).
- Сборка Android один раз упала из-за блокировки файла другим процессом
  (вероятно, IDE); повтор прошёл. К коду отношения не имеет.
