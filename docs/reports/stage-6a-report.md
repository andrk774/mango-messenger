## 2. Группы — [ADR-0020](../adr/0020-group-membership-and-roles.md)

**Сервер:** переименование, добавление участников, исключение и выход,
смена ролей и передача владения. Ровно один владелец; при его уходе
владение переходит самому давнему администратору или участнику; ушёл
последний — группа удаляется. Изменения сериализуются блокировкой чата,
повторы безопасны.

Каждое изменение — системное сообщение со структурой события в общей
нумерации. Текст собирает клиент, формулировки безличные
(«Анна: исключение из группы — Борис»): приложение не знает рода
участников и не склоняет имена.

**Клиент:** создание группы в диалоге новой переписки; экран группы —
участники с ролями, действия по правам, переименование, добавление,
выход. Управление составом требует сети и об этом прямо говорит.

## 3. Вложения — [ADR-0019](../adr/0019-attachment-storage.md)

**Сервер (модуль `storage`):** разрешение на загрузку → загрузка по
подписанной ссылке → привязка к сообщению в транзакции отправки →
временная ссылка на скачивание. При приёме: белый список типов, пределы
размера (принимается не больше заявленного), сверка SHA-256, сигнатура
содержимого против заявленного типа. Хранилище — каталог на томе за
интерфейсом `BlobStorage`, замена на S3 не меняет клиентов.

**Клиент:** выбор файла системным диалогом (без разрешения на всё
хранилище) → копия в личный каталог с подсчётом хеша → сообщение сразу
в переписке → в очереди две операции: загрузка файла и отправка
сообщения, зависящая от неё. Прогресс загрузки виден в переписке.
Картинки показываются превью, файлы открываются внешним приложением
через FileProvider. Передача файлов идёт без токена пользователя.

сценариев, а не вокруг отдельных функций.

## 6. Что не сделано или не проверено

- **Запуск на устройстве** — выбор файла, превью, открытие PDF, прогресс
  загрузки видны только в коде.
- **Очистка хранилища:** непривязанные вложения и файлы удалённых сообщений
  остаются на диске.
- **Антивирусной проверки нет** — только сигнатура типа (ADR-0019).
- **Докачки нет** — ни при загрузке, ни при скачивании (Range).
- Одно вложение на сообщение в интерфейсе (сервер принимает до 10).
- Голосовые сообщения: тип есть, записи в интерфейсе нет.
- Аватары групп, приглашения по ссылке, скрытие истории до вступления.
- Превью картинки — исходный файл, без уменьшенной копии: в ленте
  с большими фотографиями это заметно по памяти и трафику.
