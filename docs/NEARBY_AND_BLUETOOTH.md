# Люди рядом и Bluetooth

Android: **Настройки → Люди рядом**. Внутри доступны поиск по местоположению и Bluetooth.

## По местоположению

При первом открытии пользователь соглашается на публикацию профиля и разрешает
приблизительное местоположение Android. После согласия видимость автоматически
включается при открытии экрана на срок до 2 минут. Предпочтение хранится отдельно
для каждого аккаунта на телефоне. «Скрыться» выключает текущую видимость, а
«Отключить автоматическую видимость» отменяет включение при следующих открытиях.
Клиент и сервер округляют координаты
до сетки 0,02 градуса. Поиск охватывает примерно 10 км; другим возвращаются
только ID, имя и username, без координат, точного расстояния и сортировки по нему.
Нажатие на найденного человека открывает обычный личный чат.

Нужны интернет/доступ к серверу, сетевой провайдер местоположения и добровольная
видимость обоих участников. В фоновой геолокации нет необходимости, разрешение
на неё не запрашивается. При уходе с экрана клиент пытается скрыться; при отсутствии
сети сервер перестаёт показывать запись через 120 секунд. Просроченные координаты
удаляются из памяти с периодом до 5 секунд. В базу они не записываются.

API: POST/GET/DELETE `/v1/nearby`, действующий JWT обязателен. GET требует собственной
видимости в той же сессии. Выход из аккаунта, блокировка и отзыв сессии исключают
пользователя из выдачи. POST ограничен 2 запросами за 2 минуты, GET — 12 за минуту.
Координаты не меняются внутри текущего периода видимости. Результат ограничен
100 участниками. Хранилище рассчитано на один экземпляр backend: для нескольких
реплик нужен общий TTL-store. Поиск не подтверждает физическое присутствие:
поддельная геолокация и несколько аккаунтов остаются возможными.

## Bluetooth без интернета

1. Сопрягите два телефона в системных настройках Bluetooth.
2. Откройте режим Bluetooth в Mango на обоих телефонах.
3. Обновите список сопряжённых устройств и выберите друг друга.
4. На одном телефоне нажмите «Ожидать», на другом — «Подключиться» в течение 30 секунд.
5. Отправьте текст. Пометка «получено» означает подтверждение принимающим экраном.

Используется защищённый RFCOMM с системным сопряжением. Android 12+ запрашивает
разрешение Nearby devices/BLUETOOTH_CONNECT. Сканирование и постоянная видимость
телефона не включаются приложением; первичное сопряжение выполняется пользователем
в настройках Android. Имя устройства **не удостоверяет аккаунт Mango** — сверяйте
телефон с собеседником. Это не MLS и не новая реализация E2EE приложения.

Режим поддерживает только личные текстовые сообщения до 4096 байт UTF-8. В памяти
экрана остаются последние 100 сообщений, на диске они не сохраняются. Нет передачи
файлов/голосовых, групп, маршрутизации через другие телефоны, доставки на расстояние
через интернет или объединения с серверной перепиской. После ухода в фон связь
закрывается; при новом подключении экран истории очищается. Автоматической
повторной отправки неподтверждённых сообщений нет.

## Проверка

Новые автоматические тесты: `NearbyTest` (3), `NearbyIntegrationTest` (1, настоящий
PostgreSQL и Ktor HTTP), `BluetoothFrameTest` (3). Проверяются согласие, истечение
видимости, скрытие, границы координат, область поиска, сессия, авторизация,
кадрирование UTF-8/ACK и отклонение чрезмерных, повреждённых и обрезанных кадров.

Реальный обмен между двумя телефонами требует отдельной приёмки. Автотесты формата
не подтверждают работу радиоканала. Не считать этот режим проверенным на двух
Android-устройствах до фактического теста.

22 ноября 2026: семь новых тестов прошли, подписанный release APK собран,
подпись проверена `apksigner`, обновление через `adb install -r` установлено
на Galaxy без удаления приложения. Локальный backend обновлён до образа
`mango-backend:nearby-20261122`; health вернул 200, а запрос nearby без токена — 401.
Предыдущий образ сохранён как `mango-backend:before-nearby-20261122`.
Release-сборка завершилась успешно, но R8 вывел предупреждения о чтении Kotlin
metadata после предыдущего обновления Kotlin; совместимость инструментов остаётся
отдельным вопросом аудита. Это не подтверждение полного release-регресса.

Использованы официальные интерфейсы Android:
[разрешения Bluetooth](https://developer.android.com/develop/connectivity/bluetooth/bt-permissions),
[соединение RFCOMM](https://developer.android.com/develop/connectivity/bluetooth/connect-bluetooth-devices).
