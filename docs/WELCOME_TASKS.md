# Первые шаги в Mango

После успешного подтверждения email сервер создаёт четыре приветственных задания:
аватар, приглашение, первый чат и первая задача. Создание входит в ту же транзакцию,
что и подтверждение. Первичный ключ `(user_id, kind)` предотвращает дублирование;
повторное подтверждение не сбрасывает прогресс. Для ранее подтверждённых аккаунтов
задания задним числом не создаются.

Это отдельный учебный список, а не рабочие задачи команды. В Android доступен через
«Первые шаги в Mango» в чатах и «Знакомство с Mango» в задачах; в веб-версии — через
«Первые шаги». Каждое задание содержит инструкцию, иллюстрацию на компонентах интерфейса
Mango и кнопку действия. Статусы «Выполнено» и «Пропущено» отмечаются вручную и сохраняются
для аккаунта на сервере. Открытие экрана и вызов системного меню приглашения не означают
выполнение. При ошибке сети статус не меняется, можно повторить запрос.

Приглашение содержит адрес текущего сервера. Для локального развёртывания получателю
нужны доступ к домашней сети, разрешение имени сервера и доверие к локальному сертификату.
Публикация ссылки не превращает локальный сервер в публичный.

## API

- `GET /v1/users/me/welcome` — массив `{kind,status}` текущего пользователя.
- `POST /v1/users/me/welcome/{kind}` — JSON `{"status":"DONE"}` или `{"status":"SKIPPED"}`.
  Допустимые kind: `AVATAR`, `INVITE`, `CHAT`, `TASK`. Повторный запрос не создаёт задания.
- `POST /v1/users/me/avatar` — JSON `{"image":"<base64>"}`, до 350000 символов.
  Сервер проверяет формат, ограничивает размеры 512×512 и перекодирует в JPEG.
  Возвращает `{avatarUrl}` с data URL; фото хранится в профиле и попадает в резервную копию БД.

Все маршруты требуют действующей авторизации и не принимают чужой user ID.

Android уменьшает выбранное фото до 512 пикселей перед отправкой. В карточке задачи
доступно напоминание в местном времени телефона; оно отправляется через существующую
офлайн-очередь как изменение `remind_at`. Веб-карточка также позволяет установить
или очистить напоминание. Доставка уведомления требует работающего backend и настроенных уведомлений.
