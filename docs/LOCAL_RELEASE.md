# Локальная версия: выпуск и обслуживание

Публичный сервер и почтовый провайдер пока не выбраны. Mailpit сохраняет тестовые письма на компьютере; он не доставляет их в Gmail или другие внешние ящики.

## Подключение

Компьютер и телефоны должны находиться в одной доступной локальной сети. Backend слушает localhost:8081; Caddy предоставляет HTTPS на 443 с именем mango.home.arpa. APK содержит локальный CA. При включённом VPN доступ к локальной сети должен быть разрешён пользователем. Резервный IP в APK необходимо пересобирать при смене адреса компьютера.

Для USB-сборки: `adb reverse tcp:8081 tcp:8081`. После отключения USB этот маршрут недоступен. Не использовать USB-успех как доказательство работы домашней сети.

## Почта

По умолчанию используется Mailpit на http://127.0.0.1:8026. Для будущего SMTP задаются переменные в локальном `.env`: `MANGO_SMTP_HOST`, `MANGO_SMTP_PORT`, `MANGO_SMTP_SECURITY` (STARTTLS для 587 или TLS для 465 по требованиям провайдера), `MANGO_SMTP_USERNAME`, `MANGO_SMTP_PASSWORD`, `MANGO_MAIL_FROM`. Авторизация без TLS запрещена. Реальная доставка требует отдельной проверки с выбранным провайдером.

## Резервные копии

`powershell -File scripts/backup-local.ps1` создаёт новый каталог в artifacts/backups, дамп PostgreSQL, копию вложений и SHA256-манифест. Существующие копии не перезаписываются и не удаляются. Для согласованности БД и файлов следует выполнять копирование в период без записи. Копия на том же диске не защищает от отказа диска; хранить дополнительную защищённую копию отдельно.

`powershell -File scripts/verify-backup.ps1 -BackupDirectory <путь>` проверяет хеши и восстанавливает дамп в новую изолированную БД, не затрагивая рабочую. Тестовая БД и временные дампы сохраняются. Скрипт не выполняет очистку.

Секреты Firebase, .env, ключ подписи APK и локальный CA требуют отдельного защищённого резервирования. Они не включены в обычный архив приложения.

## Проверка перед выпуском

- Backend: gradlew.bat test; Android: testDebugUnitTest, :core:common:test, :core:model:test и assembleDebug.
- Локальный стек: scripts/smoke-test.sh; проверить /v1/health, журналы ошибок и доступность Mailpit.
- Два телефона: регистрация, код, вход, сообщения в обе стороны, группы, вложения, задачи, офлайн и возврат сети, уведомление в фоне, выход и смена аккаунта.
- Для каждой новой функции: положительный сценарий, отказ в доступе к чужим данным, повтор запроса и синхронизация второго устройства.
- Обновить APK поверх установленного без очистки данных; проверить сохранность истории и сессии.

Debug APK не является подписанным выпуском для распространения. До релиза требуется отдельный ключ и защищённая копия ключа; публикация и покупки не выполняются автоматически.
